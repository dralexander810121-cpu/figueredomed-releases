## Sobre el aviso de SmartScreen al instalar en Windows

Como esta version no tiene certificado EV de firma de codigo (cuesta 300 USD/año), Windows mostrara un aviso al instalar. Es normal y seguro:

1. Clic en **Mas informacion**
2. Clic en **Ejecutar de todos modos**
3. La instalacion continua normal
